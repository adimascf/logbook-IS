Literature review on IS elements (week 01 and week 02)

Inserion sequences (IS) are small, simple transposable DNA element, that can move (“transpose”) within a genome.

  • Size: typically 0.7 - 2.5 Kb
  • Main function: They carry no genes other than transposase, the enzyme that catalise their movement
  • Abundance: > 4000 IS types have been currated and identified (ISfinder). Using more computational methods, Kirsch et al (2024) found 22,713 unique IS, and stored at ISOSDB. These difference will be discussed in the week 10 and 11.
  • Role: key drivers of bacterial genome evolution, rearrangements, horizontal gene transfer (HGT), and adaptation, especially under stress or antibiotic exposure.

They move in different ways:

  • Cut-and-paste: the IS is removed from one site and inserted into another.
  • Copy-and-paste: a new copy is made and inserted elsewhere, leaving the original behind.
  • Copy-out–paste-in: the IS forms a circular intermediate before inserting into a new site.

An IS element typically contains:

  • Transposase gene (tnp): ORF responsible for cutting and joining DNA. Common catalytic motif: DDE (Asp–Asp–Glu) or DEDD, defining major IS families.
  • Inverted Repeats (IR): Shor (10-40 Kb) (sometimes imperfect) inverted complementary sequences at bot ends making IS boundaries.
  • Target Site Duplication (TSD): Short direct repeats (3-14 Kb) generated when IS integrates into the genome

IS elements are grouped into families based on:

  • Transposase motifs (e.g. DDE, HUH)
  • Structure and organization (single or multiple ORFs)
  • IR type and TSD length
  • Transposition mechanism (cut-and-paste or copy-and-paste)

Examples of families:

  • IS1, IS3, IS4, IS6, IS26, IS630, IS911
  • IS26 is notable for spreading antibiotic resistance genes and reorganizing genomes via cointegrate formation.

IS elements can impact nearby genes by:

  • Disrupting coding sequences, turning functional genes into psedogenes or unfunctional genes
  • Bringing their own promoters, which can upregulate (sometimes anibiotic resistance) genes, such as ISAba1 increasing OXA and ampC expression in Acinetobacter baumannii.
  • Interupting regulatory genes, leading to overexpression of the downstream genes, as seen when IS21 disrupts mexR in Pseudomonas aeruginosa
  • Promoter read-through, where the IS and nearby genes are co transcribed, increasing gene expression.

Playing around with assemly graph (week 03)

WGS using short read sequencing presents challenges for IS detection, as multiple copies of IS in different locations represent repeats that are longer than the read length. An assembly algorithm, such as de Brujin graph, collapse these repeats into a single path, resulting in multiple branches entering and exiting the node. This branching leads to fragmentation of the assembly into contigs

Understand eris codebase (week 04)

Eris is a Python package that detects insertion sequence (IS) elements in bacterial genomes and quantifies how they affect nearby genes. Designed for both command-line users and developers, Eris combines a robust API with lightweight dependencies and seamless installation. It scans for IS elements in input sequences provided in FASTA or GFA format through the following steps:

  • Eris scan pipeline, using minimap2 at core, will align IS elementt sequence from ISfinder database against the input sequence, and can accept contigs or full sequence
  • The resulted alignment then sorted and culled to get high scoring query in that region, eris then will tag IS element as “mobile_element”
  • Eris also will predict CDS using pyrodigal
  • Eris search the promoters in the sequence using regular expression,
  • It then convert the sequence into feature graph to represent the correlartion CDS, IS element, and promoter
  • We implemented breadth first seach (BFS) to find the CDS that either part of the element (inside) or adjacent of the IS elements
  • Eris reports the location of IS with resepct of each CDS (downsteam, upstream, flanking, and insdie), and based on that, it predict the raltive effect of the IS element to CDS feature

Check The IS names and is their copies - the simple one

This is how I calculate the TP, FN, FP:

from collections import defaultdict

def calculate_is_metrics(truth_is_copies: dict[str, int],
                        predicted_is_copies: dict[str, int]) -> tuple[dict, list]:
    """
    Calculate assessment metrics based on identified IS names and their copies
    against the truth annotation
    """

    # Combine all unique IS name keys
    all_is_names = set(truth_is_copies.keys()) | set(predicted_is_copies.keys())

    # Initialize total counts
    TP_total = 0
    FP_total = 0
    FN_total = 0

    # Data structure for figure generation (per IS name results)
    results = defaultdict(lambda: {'Truth': 0, 'Predicted': 0, 'TP': 0, 'FP': 0, 'FN': 0, 'Difference': 0})

    # Calculate TP, FP, FN for each IS name
    # This calculation doesn't consider the location in the genome
    for is_name in sorted(all_is_names):

        # If IS name doesn't appear in the truth, give it 0 count
        T_c = truth_is_copies.get(is_name, 0)
        # If IS name doesn't appear in the prediction, give it 0 count
        P_c = predicted_is_copies.get(is_name, 0)

        # True Positives (TP): minimum of True and Predicted counts
        TP_i = min(T_c, P_c)

        # False Positives (FP): overcall
        FP_i = max(0, P_c - T_c)

        # False Negatives (FN): undercall/missed
        FN_i = max(0, T_c - P_c)

        # Accumulate totals
        TP_total += TP_i
        FP_total += FP_i
        FN_total += FN_i

        # Store per name results
        results[is_name]['Truth'] = T_c
        results[is_name]['Predicted'] = P_c
        results[is_name]['TP'] = TP_i
        results[is_name]['FP'] = FP_i
        results[is_name]['FN'] = FN_i
        results[is_name]['Difference'] = P_c - T_c

    return results, [TP_total, FP_total, FN_total]
